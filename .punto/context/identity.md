# Chat MCP Publisher — Identidad

Chat MCP Publisher es un proyecto público de Punto por Punto alojado en `PuntoxPunto/chat-mcp-publisher`.

## Project ID

`chat-mcp-publisher`

## Repository

`PuntoxPunto/chat-mcp-publisher`

## Propósito

Convertir prompts, workflows y habilidades reutilizables en apps MCP remotas para ChatGPT Web, con énfasis en diseño de tools, compatibilidad moderna/legacy, deployment AppDeploy, QA y entrega del endpoint correcto para Developer Mode.

## Rol dentro de Punto por Punto

El proyecto conserva su implementación y memoria específica en su propio repositorio. Punto por Punto puede registrarlo, montar su Project Pack y relacionarlo explícitamente con otros proyectos sin duplicar esa memoria como una segunda fuente de verdad.
